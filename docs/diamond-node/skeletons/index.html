The Four Mathematical Skeletons

Independent mathematical structures that recur across physical systems

Across eleven scientific domains, the same four mathematical frameworks appear independently. Each was discovered multiple times by communities that don't read each other's journals. Each produces two emergent properties at different depths: a structural property ("has") and a functional property ("does"). Together they decompose the multi-critical profile of any physical system.

Skeleton 1: Topology

Protection → Fault-tolerant computation
Braid groups, knot invariants, topological protection. Three strands, two crossings, infinite consequences. Alternating braid crossings create Fibonacci growth, giving the golden ratio φ = 1.618... as a binary tracer: it either shows up in the system or it doesn't.
7 independent communities — from pure mathematics (1860s) to active matter (2010s)

Skeleton 2: Dynamics (Criticality)

Spontaneity → Coherent transport
Phase transitions, power laws, scale invariance, renormalization group. The anchor skeleton — the best-understood of the four, documented in the FACETS paper (arXiv 2601.22389). Criticality runs through every system in the multi-critical tutorials.
12 independent fields — see the six system tutorials

Skeleton 3: Closure

Self-sustenance → Self-creation
Catalytic loops, RAF theory, autopoiesis. A campfire sustains itself. A cell creates itself. No tracer molecule — closure is a structural property of the network, not a numerical signature. Detection requires the full wiring diagram.
8 formalizations across 6 independent discoveries, 4 countries, 50 years

Skeleton 4: Computation

Universality → Coordination
Distributed computation, cellular automata, edge of chaos. Simple local rules producing global information processing without central control. The edge of chaos IS the critical point — this is where Skeleton 4 meets Skeleton 2.
8 fields — from Turing (1936) to reservoir computing (2000s)
