Lattice Braiding Search

Spatially extended Fibonacci anyon braiding on 60-site chains — searching for genuine complexity

Overview

The braiding phase space search established that single-rule repetition on a finite Hilbert space cannot produce genuine complexity. This search extends to spatially extended systems: 1D lattice chains where different braiding rules operate at different sites, producing emergent spatiotemporal patterns.

The motivation is physical: real topological systems involve many anyons distributed in space. Complexity might emerge from the interplay between local quantum dynamics (braiding) and spatial structure (the lattice pattern), even when each local operation is simple.

Method

Lattice model. A 1D chain of 60 Fibonacci anyons. Each adjacent pair has a local 2D fusion space. At each time step:

  1. Apply braiding unitary UA or UB at each site according to a spatial pattern
  2. Apply F-matrix coupling to propagate information between neighbors (coupling strength 0.3)

Rule selection. The top 50 rule pairs were selected from the single-rule search, ranked by commutator norm (maximizing non-commutativity of the two rules).

Spatial patterns. 12 pattern types tested: uniform A, uniform B, alternating, period-3 (AAB), period-4 (ABBA), Fibonacci word, three random densities (30%, 50%, 70%), block (half/half), gradient, and Thue-Morse.

Two models:

  • Linear model: Braiding rule at each site determined by the fixed spatial pattern. Product-state approximation (no entanglement between sites).
  • Nonlinear model: Braiding rule at each site depends on the current state of its neighbor (if P(τ) > threshold, use rule B; otherwise rule A). This is a true CA with state-dependent update rules.

Total simulations: 1,570 (50 rule pairs × 12 patterns × 2–3 configurations, plus nonlinear variants).

Honest Assessment

The linear "Class IV" candidates are not genuinely complex.

Close inspection reveals that the 54 candidates classified as Class IV are domain-wall interference patterns: standing and traveling waves created by the boundary between regions with different braiding rules. These patterns have spatial structure, but they lack the hallmarks of genuine complexity:

  • No gliders or localized propagating structures
  • No information processing or logical operations
  • No sensitivity to initial conditions beyond the initial transient
  • Spatial Fourier spectra are discrete (quasi-periodic), not broadband

The nonlinear model shows period-doubling to chaos with no complex intermediate. The threshold mechanism is too blunt: it creates a binary switch that locks in quickly, destroying the spatial structure that might support complexity.

The Fundamental Bottleneck

Product-state approximation strips out entanglement.

Both models use a product-state (mean-field) approximation: each site's state is independent of its neighbors, coupled only through the F-matrix at each time step. This is computationally tractable (the state is 60 × 2 complex numbers, not a 260-dimensional vector), but it discards the very thing that makes quantum systems quantum: entanglement.

In a full quantum simulation, braiding would create entanglement between sites. This entanglement is where the complexity lives. The topological properties that make Fibonacci anyons computationally universal are properties of the entangled many-body state, not properties that can be captured in a product-state approximation.

The null result is therefore expected and informative: it confirms that complexity in topological systems is a genuinely quantum phenomenon, not a classical one dressed in quantum language.

Paths Forward

Four approaches could break through the entanglement barrier.
  1. Matrix Product State (MPS) simulation. Represent the chain as an MPS with bond dimension chi. This captures entanglement up to chi correlations. Cost: O(N chi3) per step. For 60 sites at chi=64, this is feasible on modern hardware. The question: does entanglement entropy grow with time (indicating genuine complexity) or saturate (indicating topological order without dynamics)?
  2. Measurement-based dynamics. Intersperse braiding with projective measurements. This breaks unitarity and can create genuinely irreversible dynamics. The measurement collapses entanglement locally, but the braiding re-creates it. The interplay might support complex dynamics.
  3. Dissipative coupling (Lindblad dynamics). Add controlled decoherence via a Lindblad master equation. This models a topological system coupled to an environment. Dissipation breaks unitarity and can drive the system to non-equilibrium steady states with complex structure.
  4. Smooth nonlinear feedback. Replace the binary threshold with a smooth function (e.g., tanh with adjustable steepness). The binary threshold is a singular limit that destroys intermediate behavior. A smooth feedback function might support a richer dynamical landscape.
