Braiding Phase Space Search

NKS enumeration of Fibonacci anyon braiding rules, classified by Wolfram's four complexity classes

Overview

This search systematically enumerates braiding rules on Fibonacci anyons and classifies the resulting dynamics by Wolfram's four complexity classes (the NKS approach). The goal: determine whether any braiding rule on a finite fusion space can produce genuine Class IV (complex) behavior—the kind of dynamics that supports computation.

Fibonacci anyons have two particle types: 1 (vacuum) and τ. Their fusion rule is τ × τ = 1 + τ. For n anyons fusing left-to-right, the state space dimension follows the Fibonacci sequence: F(n−1). Braiding is represented by unitary matrices (R-matrices composed with F-matrices) acting on this fusion space.

Method

Braid word enumeration. For n=3 anyons (2D fusion space), the braid group generators are σ1 and σ2, each with an inverse. A braiding rule is a word in {σ1, σ1−1, σ2, σ2−1} of length 1 through 5. This gives:

  • n=3: 1,364 rules (lengths 1–5, 4 generators per position)
  • n=4: 258 rules (lengths 1–3, 6 generators per position, 3D fusion space)

Classification. Each rule is iterated 200 times from a random initial state. The trajectory is classified by:

  • Class I (fixed point): trajectory converges to a fixed state
  • Class II (periodic): trajectory repeats with detectable period
  • Class III (chaotic): positive Lyapunov exponent, sensitive dependence
  • Class IV (complex): intermediate—neither periodic nor fully random

Physics verification. Each composite braid matrix is checked for unitarity (σσ† = I) and eigenvalue structure. Yang-Baxter satisfaction is verified for the physical R-matrices.

Critical observation: Zero Class III in both searches. And the "Class IV" candidates are not genuinely complex—they are quasi-periodic, as explained below.

Key Finding: No Genuine Chaos

Unitary evolution on finite Hilbert space cannot produce chaos.

This is provable from first principles. A braiding rule acts as a unitary matrix U on the fusion space. Iteration produces the sequence U, U2, U3, ... The eigenvalues of U are phases eiθj. After n iterations, the state components evolve as einθj.

This evolution is linear and norm-preserving. The Lyapunov exponent is exactly zero: nearby trajectories neither converge nor diverge. There is no sensitive dependence on initial conditions.

If all eigenvalue phases θj/2π are rational, the trajectory is exactly periodic (period = LCM of denominators). If any phase is irrational, the trajectory is quasi-periodic—it never exactly repeats but fills a torus densely. This quasi-periodicity can mimic complexity over short timescales, which is why these candidates appear as "Class IV" in the NKS classifier. But they are not genuinely complex: they have zero entropy rate and no computational capacity.

The 360 Class IV candidates (n=3) all have irrational eigenvalue phases related to φ = (1+√5)/2. They are dense quasi-periodic orbits on a 2-torus, not complex dynamics.

Implication

Complexity cannot emerge from single-rule repetition on a finite-dimensional Hilbert space. This is a structural limitation, not a failure of search: the mathematics of unitary evolution forbids it.

For genuine complexity to arise from anyon braiding, we need spatial extent: a lattice where different braiding rules operate at different sites, producing emergent spatiotemporal patterns that are not captured by any single unitary matrix. This is the motivation for the lattice extension.
