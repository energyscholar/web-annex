Criticality Math Kernel

the ABR kernel (formerly ABRCE) — Kernel V9, development branch

The ABR kernel is a small set of rules for turning measurements into arrows and then reading how much changes along each arrow — without ever adding an arrow, a number or a direction that nobody observed.

Five words, one minute
  1. Observation: what an instrument or a person actually recorded.
  2. M: the written rule that turns an observation into a number: its projection, not the thing.
  3. Arrow: “from here to there”, the way the observation went. One observation, one arrow.
  4. Declared: written down, with its observation, before any arithmetic.
  5. Operator: a fixed arithmetic step. Five names, Δ A Σ B R, four formulas (Δ = A). Operators read change, never create it.

What it is

Most mathematics builds relations out of objects. This kernel starts from one primitive: a directed relation declared from observable information. The rest is fixed arithmetic on the arrows’ numbers, and a result is a calculation, never an observation.

What it does: try it

Three points, two declared arrows. A takes each arrow’s difference; B adds the next arrow’s, one step only; R adds what continues minus what arrives, scaled by the local contrast ρ. Untick the middle point: B is not evaluated, which is not zero.

Why the rules are strict

One observation, one arrow. A reverse arrow needs its own observation; a loop’s closing arrow is refused.

Nothing undeclared enters. A step missing a declared number is not evaluated, never filled in; a genuine zero is kept.

Say what you threw away. Every summary states what it keeps and discards.

Where it comes from

The preprint Convergent Discovery of Critical Phenomena Mathematics Across Disciplines (Stephenson & Macomber, arXiv:2601.22389) surveys six to twelve fields that built tools for the same question. Its supplement records that the framework that preceded this kernel, from distributed systems engineering, resembled a critical phase transition near its parameter boundaries; that prompted the survey. ★ one of the six clearest cases, each, in the preprint’s words, “with qualifications noted for each”.

  • Independent derivation: developed from first principles without demonstrable awareness of equivalent prior work.
  • Qualified independent: the method is novel, but the researcher’s training or setting included significant exposure to the relevant physics.
  • Domain transfer: an existing technique applied to a new domain, with traceable lineage.
  • Intra-physics extension: new phenomena found with existing tools inside the same discipline (the definition says “intra-field”).
  • Empirical precursor: critical-like behaviour observed before the formal framework existed.
  • Foundational framework, foundational cross-domain: the general mathematics (scaling, self-similarity, power laws) that shaped several lineages; statistical physics “established the mathematics”.
  • Prior cross-domain synthesis: an earlier work that already drew the fields together, a “textbook treatment”.

The preprint’s own limits

“The functional correspondence we document is phenomenological.” “Our citation analysis cannot rule out informal knowledge transfer. The quantitative evidence supports but does not prove independent derivation.” (preprint, Limitations)
