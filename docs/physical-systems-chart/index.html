▶ AC Topology ↔ Autocatalysis — Physical Identity FQHE candidate

FQHE systems are the strongest AC candidate. Anyonic quasiparticles are collective excitations generated by the substrate (Nayak et al. 2008 — Established), so the generation criterion is arguably satisfied physically and not only algebraically. That reading is not yet a confirmed demonstrator, and the gap-map below still scores this bridge at zero confirmed — the remaining work is to show closure, not merely generation. The AC bridge is last in the paper sequence because the sociology is hostile — these communities share no journals, conferences, or notation — not because the science is hardest.

Theoretical basis
Anyon fusion algebra satisfies RAF closure criteria at the algebraic level. In Fibonacci anyons: τ × τ = 1 + τ is self-catalytic — the fusion of two τ particles produces another τ. This is a structural identity at the algebraic level, not an analogy.

Candidate 1: FQH edge networks

Anyon production/fusion network as RAF on topological substrate
In a GaAs antidot lattice: a network of FQH edge channels with anyon fusion events at antidot junctions. If the anyon production/fusion network is self-sustaining, it would constitute an RAF on a topological substrate.
Status: HYPOTHESIS — antidot lattices exist, patterning demonstrated, but self-sustaining fusion dynamics not yet shown.

Candidate 2: Topological metamaterials with gain feedback

Amplification network as RAF on topological substrate
Topological edge states in photonic/phononic crystals coupled to a gain medium. If the feedback network is autocatalytic — the amplification process sustains itself through the topological channels — it would constitute an RAF on a topological substrate.
Status: HYPOTHESIS — topological edge states and gain media exist independently, but their combination as autocatalytic network not yet demonstrated.

Candidate 3: Magnetospheric reconnection cascades

Reconnection cascades in topologically ordered plasma
Magnetic reconnection events in the magnetotail may form cascade networks in plasma with non-trivial topological band structure. If the reconnection cascade is self-sustaining, it would bridge topology and autocatalysis.
Status: HYPOTHESIS — highly speculative. Requires topological band structure in magnetospheric plasma to be confirmed first.
What measurements would confirm
Demonstrate self-sustaining anyon production/fusion dynamics in a patterned FQH system at the plateau transition. The key measurement: does the anyon fusion network self-sustain? If fusion products catalyze production of new anyons, and this forms a closed network, the AC bridge is established.

5. Bridge Mechanism Taxonomy

Four distinct types of bridge mechanism have been observed. The correlation between mechanism type and bridge strength may not be coincidental.

Type 1: Rule-space structural identity

Bridges: CB, CD-a, BD, AC (if confirmed) — ~4 bridges

Both endpoints are complex systems whose rule spaces share the same mathematical structure. The bridge is not an analogy — it is a provable isomorphismA one-to-one mapping between two mathematical structures that preserves all operations and relationships. If two systems are isomorphic, anything you can prove about one is automatically true of the other — they are the same system wearing different labels. between rule spaces. At the critical point, the systems are literally the same mathematics.

Example: a Boolean network at K ≈ 2 is a cellular automaton in the directed percolation universality class. This is not a metaphor; the dynamical systems are mathematically identical at the RG fixed point.

Type 2: Topological protection

Bridges: AB — ~1 bridge

Topology provides the invariant that stabilizes structures from another domain. The bridge mechanism is protection/stabilization rather than identity. The topological chargeA quantity (like a winding number or Chern number) that counts how many times a field configuration wraps around a mathematical space. It can only change in integer steps, so it acts like a lock — the system cannot smoothly deform away from its current state. (winding number, Chern number) prevents the solitonic structure from dispersing or unwinding.

Example: skyrmions are stable because their homotopy class π2(S2) = ℤ prevents continuous deformation to the vacuum state.

Type 3: Co-emergence at criticality

Bridges: BC — ~1 bridge

Both phenomena emerge from the same critical point in the same physical system. They co-occur because criticality generates both simultaneously. The bridge is the shared bifurcation.

Example: in the BZ reaction, the Hopf bifurcationA critical point where a stable steady state suddenly begins to oscillate. Below the threshold: the system sits still. Above: it rings like a bell. The oscillation frequency and amplitude are set by the mathematics, not the specific system — chemical reactions, neurons, and lasers all exhibit the same Hopf transition. simultaneously produces both the solitonic structures (spiral waves) and the autocatalytic dynamics. They are two aspects of the same phase transition.

Type 4: Fixpoint/eigenform

Bridges: CD-b — ~1 bridge

The bridge is a self-referential fixed point where the system produces its own description. Louis Kauffman's eigenform theory: an object is a fixed point of the process of observation. The system's organizational closure (autopoiesis) is the same mathematical structure as a computable fixed point.

The most philosophical, least formalized bridge type. Category-theoretic fixed points may provide the path to formalization.

Pattern: The Type 1 bridges (rule-space identity) are exactly the robust primary bridges with multiple demonstrators. The other types correspond to the fragile or single-demonstrator bridges. Structural identity is a stronger connection than co-emergence or protection — identity bridges are harder to break because they are mathematical truths, not empirical coincidences.

If AC is confirmed as a Type 1 bridge (rule-space identity between anyon fusion algebras and RAF closure), it would immediately be a strong bridge — not fragile — because the connection would be mathematical rather than merely observational.

Prioritized by which measurements or computations would most advance the bridge network.

  • Compute: NKS search for Class IV braiding rules on an anyon lattice NULL RESULT — the search has been run and reported: 1,364 single rules at n=3, zero genuine Class IV, and 1,570 lattice simulations in which the 54 apparent Class IV candidates proved to be domain-wall interference.
