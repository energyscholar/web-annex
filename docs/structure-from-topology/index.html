Structure from Topology

How typed operators on multiple topologies reveal hidden coherence. A worked example from magnetospheric physics.

Abstract

When data carries multiple independent structures—spatial, spectral, temporal—standard practice analyzes each one separately, projecting away the others. Some features exist only in the coupling between structures and are invisible to any single-structure analysis, not because they are faint but because they are structurally absent from every projection.

We present a minimal framework for coupled multi-topology analysis built from two field types (NodeField, EdgeField) and three operators (A, B, R) whose composition order is forced by their type signatures, not chosen by the analyst. The first operator, A, is the unique NodeField→EdgeField transition satisfying translational invariance. A and B operate within each topology independently; R couples topologies through a directed cycle. No optimization target, loss function, or model selection is involved.

Applied to magnetospheric satellite data with spatial, spectral, and temporal topologies, the coupled kernel resolves field-aligned currents and injection boundaries—cross-topology features that do not appear in any single-topology projection. The mathematical structure is purely relational and transfers across domains without modification.

1. What Projections Throw Away

You know what a projection does to a vector space. Project ℝ3 to ℝ2 by dropping a coordinate and you lose everything the dropped coordinate carried. If coordinates are independent, no harm. If they correlate, the projection distorts the surviving structure.

This is not unique to linear algebra. Any time your data has multiple natural structures and you analyze one at a time, you are projecting. Spatial analysis of a multi-energy dataset throws away spectral structure. Spectral analysis at a fixed location throws away spatial context. Temporal analysis at a fixed point discards everything about how the signal propagates.

Standard practice treats this as acceptable: analyze each structure independently, combine the results. But some features exist in the coupling between structures. They are not hidden in any single projection—they are absent from it. No amount of spatial analysis at any resolution will find a feature that is defined by the relationship between spatial and spectral structure. The feature is not faint; it is structurally invisible to single-topology analysis.

What you need is not a better projection. It is a way to compose the topologies.

2. Two Field Types

Consider a finite set of nodes connected by some adjacency relation—a graph. Data on this graph takes one of two forms, and this distinction is not a design choice. It is the minimum structure needed to separate where something is from how things relate.

Definition (NodeField)

A NodeField assigns one scalar value to each node. It describes the state at a location. A NodeField has no inherent directionality—the value at node i is just xi.

Definition (EdgeField)

An EdgeField assigns one scalar value to each directed pair of adjacent nodes. It describes the relationship between locations. An EdgeField is inherently directional: the value on edge (i, j) need not equal the value on edge (j, i).

These are the only two representation types. Every quantity in the framework is either a NodeField (one value per node) or an EdgeField (one value per directed adjacency pair). There is no third type.

The left panel shows a NodeField: four nodes with scalar values {3, 7, 5, 1}. The right panel shows an EdgeField on the same graph: each directed edge carries a signed value. Notice that opposite directions carry opposite signs: the A→B edge reads +4 while B→A reads −4. This antisymmetry is not imposed—it is a consequence of how the EdgeField was produced. We define that operator next.

3. The Unique Bridge

How do you move from a NodeField to an EdgeField? There is exactly one natural transition, and its uniqueness is forced by a single requirement: translational invariance.

Definition (Operator A : NodeField → EdgeField)

For a NodeField x and each directed edge (i, j):

A(x)ij = xj − xi

A extracts the pairwise difference—the relational gradient between adjacent nodes.

Why unique. Suppose we want a function F : NodeField → EdgeField that respects one structural constraint: if you shift every node value by the same constant c, the edge field should not change. Formally: F(x + c) = F(x) for all constant shifts. This is translational invariance—the absolute level of node values carries no relational information; only differences do.

For a single edge (i, j), the most general linear function of two node values is Fij = α xi + β xj. Translational invariance requires α(xi + c) + β(xj + c) = α xi + β xj for all c, which forces α + β = 0. Up to a constant scale, the only solution is xj − xi. There are no other options. A is the unique bridge from NodeField to EdgeField.

A is symmetric in a precise sense: A(x)ij = −A(x)ji. The antisymmetry of the edge field is inherited from the commutativity of subtraction. This symmetry propagates through subsequent operators and determines what structures can emerge at each stage.

Pre-A Admissibility

Because A computes pairwise differences, any transformation applied to the NodeField before A must preserve pairwise differences. Which transformations qualify?

  • Translation: T(x) = x + c. Does not alter differences. Admissible.
  • Normalization (subtract mean): Changes differences if applied non-uniformly across subsets. Inadmissible.
  • Smoothing (local averaging): Replaces each value with a weighted sum of neighbors. Alters pairwise differences. Inadmissible.
  • Interpolation: Introduces values at new nodes. Alters the adjacency structure. Inadmissible.

This is not a rule imposed on the user. It is a consequence of what A does. If you smooth the NodeField before applying A, the edge field reflects the smoothing kernel, not the data. The constraint is a theorem about the operator, not a convention about the workflow.

4. The Composition Chain

A transforms NodeField to EdgeField. Two more operators complete the chain, and both operate within EdgeField. Their order is forced by their mathematical roles.

Definition (Operator B : EdgeField → EdgeField)

B performs local relational accumulation. For each edge (i, j), B sums the edge values involving nodes i and j—aggregating the local relational context of each edge. B preserves the symmetry established by A: if the input is antisymmetric, the output remains antisymmetric.

Definition (Operator R : EdgeField × ℝ → EdgeField)

R introduces antisymmetric circulation with a bounded parameter ρ. In a single-topology setting, R rotates the edge field, breaking the input symmetry in a controlled way. The parameter ρ governs the strength of this circulation. R is the operator that breaks symmetry—and breaking symmetry is what creates structure.

Why this order is forced. A is the only operator that accepts NodeField input—it must come first. B accumulates edge structure and must follow A (you cannot accumulate what has not been extracted). R introduces cross-edge circulation and operates on the accumulated field. Reversing B and R would apply circulation to un-accumulated gradients—a local rotation of raw differences, which is degenerate. The composition E(x, ρ) = R(B(A(x)), ρ) is the only type-correct chain from NodeField to the final EdgeField.

This is not "a good design choice." It is the unique composition that type-checks. If you try any other order, you either pass the wrong type to an operator or produce a mathematically degenerate output. The chain is determined by the types.

5. Multiple Topologies

Everything above operates on a single graph—a single topology. The crucial extension is this: the same set of nodes can carry multiple independent topologies, and the R operator couples them.

In magnetospheric physics, satellite data has three natural structures:

Topology Nodes are... Adjacency means... Symbol
Spatial Measurement locations Nearby in physical space S
Temporal Time steps Adjacent in time τ
Component Energy channels Adjacent in the energy spectrum C

Each topology has its own NodeField and EdgeField. A and B operate within each topology independently: spatial A extracts spatial gradients; spectral A extracts spectral gradients. Nothing couples them yet.

The coupling comes from R. In the multi-topology extension, R passes edge-field structure from one topology to the next in a directed cycle:

Read the arrows: spatial edge structure feeds into temporal circulation. Temporal edge structure feeds into component circulation. Component edge structure feeds back into spatial circulation. The cycle is directed—the order S → τ → C → S is fixed. Reversing it gives different results because R is antisymmetric. The cycle direction is part of the structure.

Each topology runs its own A → B pipeline independently. R is the only inter-topology operator. It takes the accumulated edge field from one topology and contributes circulation to the next. The composite E(x, ρ) = R(B(A(x)), ρ) now operates across all three topologies simultaneously.

No single topology "sees" the others directly. The coupling is mediated entirely by R. This means the cross-topology structure that emerges is not injected by the analyst—it is produced by the coupling operator acting on independently-extracted gradients. If no cross-topology structure exists in the data, R produces none.

7. The Magnetospheric Case

Earth's magnetosphere is the region of space dominated by Earth's magnetic field, shaped by the solar wind into a compressed dayside and an elongated nightside tail. Satellites orbiting through this region measure particle flux across a range of energies at each point along their trajectory. The data is a function of three variables: where (spatial position), what (particle energy), and when (time).

What single-topology analysis sees

Spatial analysis alone (kriging, interpolation, variograms): treats each energy channel independently. At any given energy, the spatial map shows gradients and trends. These are real but incomplete. A sharp spatial gradient at 10 keV might be part of an injection boundary or it might be a spatial artifact. Without spectral context, you cannot distinguish them.

Spectral analysis alone (energy spectra at fixed locations): shows the energy distribution at each point. A hardening spectrum (shift toward higher energies) at one location might indicate freshly injected plasma or an artifact of the satellite's orbit. Without spatial context, you cannot tell.

Temporal analysis alone: shows how values change at a fixed point. A sudden increase might be local or global, injection or compression. Without spatial and spectral context, you cannot resolve the ambiguity.

What the coupling reveals

Apply the multi-topology kernel. Each topology runs its own A → B pipeline. R couples them through the directed cycle S → τ → C → S.

Two classes of structure emerge that were invisible in any single projection:

Field-Aligned Currents

Electrical currents flowing along Earth's magnetic field lines. They are coherent across spatial AND spectral topologies: a specific spatial pattern of particle flux at specific energies, extending along specific field-line geometries. Single-topology spatial analysis sees blurred gradients because the spectral specificity is projected away. The multi-topology coupling resolves them because the spectral–spatial R coupling preserves exactly the cross-topology coherence that defines the current.

Injection Boundaries

Boundaries where plasma from the magnetotail is injected into the inner magnetosphere. An injection boundary is a simultaneous change in spatial gradient AND spectral gradient: the spectrum hardens (shifts to higher energies) at the same spatial boundary where flux increases. This feature exists IN the relationship between spatial and spectral structure. It is not a spatial feature with spectral consequences; it is a cross-topology feature. The R operator coupling C → S is what makes it visible.

The comparison is not "sharper vs. blurrier." It is "present vs. absent." The injection boundary does not become clearer with coupling—it becomes visible for the first time. It is a cross-topology feature: defined by the simultaneous spatial and spectral gradient. No single-topology analysis at any resolution can detect it, because it does not live in any single topology.

8. No Optimization Required

Here is what the framework does not do:

  • No loss function. No cost to minimize.
  • No parameters to fit. (ρ is bounded but not optimized.)
  • No training data. No validation set.
  • No model selection. No comparison of candidate models.
  • No specification of what to look for. No target features.

The operators are defined by type constraints: A is the unique NodeField→EdgeField transition satisfying translational invariance. B is local accumulation. R is bounded antisymmetric circulation. The composition order is forced by type-checking. The multi-topology coupling cycle is determined by declaring which topologies exist.

Everything that emerges—field-aligned currents, injection boundaries, coherence patterns—is determined by the topology and the data. The kernel does not look for structure. It reveals what the topology admits.

The Structural Contrast

Standard analysis: Specify a model (target structure) → Fit parameters to data → Evaluate goodness of fit → Select among candidate models.

This framework: Declare topologies → Apply type-determined operators → Observe what emerges. The "model" is the topology itself. The operators are not chosen; they are derived. What appears is what the structure admits—nothing more, nothing less.

This is not anti-quantitative. The operators produce numerical edge fields that can be measured, compared, and tested against observations. The difference is where the structure comes from. In model fitting, structure is hypothesized and parameters are adjusted until data complies. Here, structure is a consequence of topology and type constraints. If no cross-topology coherence exists in the data, the kernel produces none. It cannot hallucinate structure that the topology does not support.

9. Coda

The pattern generalizes beyond magnetospheric physics. Any domain where data carries multiple independent structures—spatial and temporal, syntactic and semantic, physical and chemical—is a candidate for this approach:

  1. Identify the natural topologies in the data.
  2. Define NodeField and EdgeField on each topology.
  3. Apply the type-determined chain A → B within each topology.
  4. Couple the topologies through R and observe what emerges.

The composition order is not a recommendation. It is forced by the types. The coupling cycle is not a parameter. It is declared by the analyst based on domain knowledge of which structures should interact. What emerges is what the topology admits.

This is systems thinking in the precise sense: the system's behavior is determined by the structure of relationships between its parts, not by the properties of the parts themselves. The operators do not act on values; they act on differences between values. The framework is purely relational. And because it is purely relational, the mathematical structure transfers across domains without modification. Only the labels change.
